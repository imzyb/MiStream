# 07 · 数据库设计

## 1. 选型与约束

- **SQLite**（`sqlite3_flutter_libs` 随包分发）+ **drift** 作为类型安全 ORM。
- 位置：`%APPDATA%/MiStream/data/mistream.db`（macOS `~/Library/Application Support/MiStream/`，Linux `~/.local/share/MiStream/`）。
- 模式：WAL，`foreign_keys=ON`，`busy_timeout=5000`。
- 主进程独占写；子进程**不直连数据库**，插件的 `local` 存储通过 RPC 回宿主写入。
- 所有时间戳统一为 **UTC 毫秒整数**，不用本地时间、不用字符串。
- 所有表带 `id INTEGER PRIMARY KEY AUTOINCREMENT`，业务唯一性用 UNIQUE 索引表达。

## 2. ER 概览

```
config_source ──1:N──> site ──1:N──> ┌─ history
                        │            ├─ favorite
                        │            └─ download
                        └─1:N──> site_cache

plugin ──1:N──> plugin_setting
plugin ──1:N──> plugin_storage

live_group ──1:N──> live_channel
parse_rule            (独立)
setting               (独立 KV)
search_history        (独立)
app_event             (独立，诊断日志)
```

## 3. 表定义

### 3.1 `config_source` — 用户导入的配置订阅

```sql
CREATE TABLE config_source (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  name          TEXT    NOT NULL,
  url           TEXT,                       -- NULL 表示本地文件导入
  local_path    TEXT,
  raw_hash      TEXT    NOT NULL,           -- 原始内容 sha256，用于判断是否变化
  format        TEXT    NOT NULL,           -- plain | base64 | aes
  spider        TEXT,                       -- 配置根级 spider 字段：远程蜘蛛 jar URL（csp_XXX 类来源）
  spider_md5    TEXT,                       -- spider jar 的 MD5，用于缓存/更新判断
  auto_update   INTEGER NOT NULL DEFAULT 0, -- bool
  update_interval_h INTEGER NOT NULL DEFAULT 24,
  last_sync_at  INTEGER,
  last_error    TEXT,
  sort_order    INTEGER NOT NULL DEFAULT 0,
  enabled       INTEGER NOT NULL DEFAULT 1,
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL
);
CREATE UNIQUE INDEX ux_config_source_url ON config_source(url) WHERE url IS NOT NULL;
```

### 3.2 `site` — 单个数据源站点

```sql
CREATE TABLE site (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  config_id     INTEGER REFERENCES config_source(id) ON DELETE CASCADE,
  plugin_id     TEXT    REFERENCES plugin(plugin_id) ON DELETE CASCADE,
  -- config_id 与 plugin_id 恰有一个非空：源要么来自配置，要么来自插件
  site_key      TEXT    NOT NULL,           -- TVBox 的 sites[].key
  name          TEXT    NOT NULL,
  type_code     INTEGER NOT NULL,           -- TVBox site type: 0/1/3/4
  runtime       TEXT    NOT NULL,           -- js | http | python | jvm | unsupported
  api           TEXT    NOT NULL,
  ext           TEXT,                       -- 原始 ext（JSON / URL / base64）
  searchable    INTEGER NOT NULL DEFAULT 1,
  quick_search  INTEGER NOT NULL DEFAULT 0,
  filterable    INTEGER NOT NULL DEFAULT 0,
  enabled       INTEGER NOT NULL DEFAULT 1,
  priority      INTEGER NOT NULL DEFAULT 0, -- 越大越优先，影响聚合排序
  -- 运行时状态（可重建，不进备份）
  status        TEXT    NOT NULL DEFAULT 'unknown', -- unknown|ready|failing|circuit_open|unsupported
  fail_count    INTEGER NOT NULL DEFAULT 0,
  last_ok_at    INTEGER,
  last_error    TEXT,
  last_latency_ms INTEGER,
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL,
  CHECK ((config_id IS NULL) <> (plugin_id IS NULL))
);
CREATE UNIQUE INDEX ux_site_scope_key ON site(COALESCE(config_id,-1), COALESCE(plugin_id,''), site_key);
CREATE INDEX ix_site_enabled ON site(enabled, priority DESC);
```

### 3.3 `history` — 播放历史

```sql
CREATE TABLE history (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  site_id       INTEGER NOT NULL REFERENCES site(id) ON DELETE CASCADE,
  vod_id        TEXT    NOT NULL,
  vod_name      TEXT    NOT NULL,
  vod_pic       TEXT,
  flag          TEXT,                       -- 播放线路
  episode_index INTEGER NOT NULL DEFAULT 0,
  episode_name  TEXT,
  position_ms   INTEGER NOT NULL DEFAULT 0,
  duration_ms   INTEGER NOT NULL DEFAULT 0,
  finished      INTEGER NOT NULL DEFAULT 0, -- 进度 >=95% 置 1
  opening_ms    INTEGER,                    -- 片头跳过点（剧集级）
  ending_ms     INTEGER,                    -- 片尾跳过点
  play_rate     REAL,                       -- 上次倍速
  audio_track   TEXT,
  subtitle_track TEXT,
  played_at     INTEGER NOT NULL,
  created_at    INTEGER NOT NULL
);
CREATE UNIQUE INDEX ux_history_item ON history(site_id, vod_id);
CREATE INDEX ix_history_recent ON history(played_at DESC);
```

一个 `(site, vod)` 只保留一条记录，随播放更新——历史是「最近看到哪」，不是流水账。需要流水审计时看 `app_event`。

### 3.4 `favorite` — 收藏

```sql
CREATE TABLE favorite (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  site_id       INTEGER NOT NULL REFERENCES site(id) ON DELETE CASCADE,
  vod_id        TEXT    NOT NULL,
  vod_name      TEXT    NOT NULL,
  vod_pic       TEXT,
  vod_remarks   TEXT,                       -- 收藏时的更新状态
  latest_remarks TEXT,                      -- 最近检查到的更新状态
  folder        TEXT    NOT NULL DEFAULT '', -- 收藏夹分组，'' = 默认
  notify_update INTEGER NOT NULL DEFAULT 0,
  last_check_at INTEGER,
  sort_order    INTEGER NOT NULL DEFAULT 0,
  created_at    INTEGER NOT NULL
);
CREATE UNIQUE INDEX ux_favorite_item ON favorite(site_id, vod_id);
CREATE INDEX ix_favorite_folder ON favorite(folder, sort_order);
```

`vod_remarks` vs `latest_remarks` 的差异就是「有更新」的判定依据。

### 3.5 `download` — 下载任务

```sql
CREATE TABLE download (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  site_id       INTEGER REFERENCES site(id) ON DELETE SET NULL,
  vod_id        TEXT,
  vod_name      TEXT    NOT NULL,
  episode_name  TEXT,
  source_url    TEXT    NOT NULL,
  headers_json  TEXT,                       -- 下载所需的 UA/Referer
  file_path     TEXT    NOT NULL,
  media_type    TEXT    NOT NULL,           -- direct | hls
  total_bytes   INTEGER NOT NULL DEFAULT 0,
  done_bytes    INTEGER NOT NULL DEFAULT 0,
  total_segments INTEGER,                   -- HLS 分片总数
  done_segments INTEGER,
  status        TEXT    NOT NULL,           -- queued|running|paused|completed|failed|canceled
  error         TEXT,
  speed_bps     INTEGER,
  priority      INTEGER NOT NULL DEFAULT 0,
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL,
  completed_at  INTEGER
);
CREATE INDEX ix_download_status ON download(status, priority DESC, created_at);
```

HLS 分片进度另用一张 `download_segment` 表记录，支持断点续传：

```sql
CREATE TABLE download_segment (
  download_id   INTEGER NOT NULL REFERENCES download(id) ON DELETE CASCADE,
  seq           INTEGER NOT NULL,
  url           TEXT    NOT NULL,
  bytes         INTEGER NOT NULL DEFAULT 0,
  done          INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (download_id, seq)
);
```

### 3.6 `plugin` — 已安装插件

```sql
CREATE TABLE plugin (
  plugin_id     TEXT    PRIMARY KEY,        -- manifest.id
  name          TEXT    NOT NULL,
  version       TEXT    NOT NULL,
  prev_version  TEXT,                       -- 可回滚的上一版本
  type          TEXT    NOT NULL,           -- source|theme|parser|runtime|tool
  runtime       TEXT,
  install_path  TEXT    NOT NULL,
  source_market TEXT,                       -- 来源市场 URL，NULL=本地安装
  manifest_json TEXT    NOT NULL,           -- 完整 manifest 快照
  granted_permissions TEXT NOT NULL DEFAULT '{}',  -- 用户实际授予的权限
  integrity_hash TEXT   NOT NULL,
  signature_status TEXT NOT NULL DEFAULT 'unsigned', -- unsigned|valid|invalid
  enabled       INTEGER NOT NULL DEFAULT 1,
  installed_at  INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL
);
```

`granted_permissions` 与 manifest 中的声明分开存 —— 用户可能只授予了一部分。

### 3.7 `plugin_setting` / `plugin_storage`

```sql
CREATE TABLE plugin_setting (
  plugin_id     TEXT    NOT NULL REFERENCES plugin(plugin_id) ON DELETE CASCADE,
  key           TEXT    NOT NULL,
  value_json    TEXT    NOT NULL,
  PRIMARY KEY (plugin_id, key)
);

-- 插件/源脚本的 local.get/set 落到这里，按 owner 隔离
CREATE TABLE plugin_storage (
  owner         TEXT    NOT NULL,           -- plugin_id 或 'site:<site_id>'
  key           TEXT    NOT NULL,
  value         TEXT    NOT NULL,
  bytes         INTEGER NOT NULL,           -- 用于配额统计
  updated_at    INTEGER NOT NULL,
  PRIMARY KEY (owner, key)
);
CREATE INDEX ix_plugin_storage_owner ON plugin_storage(owner);
```

配额检查：写入前 `SELECT SUM(bytes) FROM plugin_storage WHERE owner=?`，超限拒绝并返回明确错误码。

### 3.8 `live_group` / `live_channel` — 直播

```sql
CREATE TABLE live_group (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  config_id     INTEGER REFERENCES config_source(id) ON DELETE CASCADE,
  name          TEXT    NOT NULL,
  sort_order    INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE live_channel (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  group_id      INTEGER NOT NULL REFERENCES live_group(id) ON DELETE CASCADE,
  name          TEXT    NOT NULL,
  logo          TEXT,
  urls_json     TEXT    NOT NULL,           -- 多个备用地址
  epg_id        TEXT,
  headers_json  TEXT,
  sort_order    INTEGER NOT NULL DEFAULT 0,
  favorite      INTEGER NOT NULL DEFAULT 0,
  last_played_at INTEGER
);
CREATE INDEX ix_live_channel_group ON live_channel(group_id, sort_order);
CREATE INDEX ix_live_channel_name ON live_channel(name);
```

### 3.9 `parse_rule` — 解析器

```sql
CREATE TABLE parse_rule (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  config_id     INTEGER REFERENCES config_source(id) ON DELETE CASCADE,
  name          TEXT    NOT NULL,
  type_code     INTEGER NOT NULL,           -- 0=嗅探 1=JSON接口 2=聚合 3=WebView
  url           TEXT    NOT NULL,
  ext_json      TEXT,
  flags_json    TEXT,                       -- 适用的播放线路
  enabled       INTEGER NOT NULL DEFAULT 1,
  priority      INTEGER NOT NULL DEFAULT 0,
  success_count INTEGER NOT NULL DEFAULT 0,
  fail_count    INTEGER NOT NULL DEFAULT 0,
  avg_latency_ms INTEGER
);
```

`success_count` / `fail_count` 用于**自适应排序**：解析成功率高的解析器自动前排，这是提升起播成功率的低成本手段。

### 3.10 `site_cache` — 源数据缓存

```sql
CREATE TABLE site_cache (
  cache_key     TEXT    PRIMARY KEY,        -- sha256(site_id + method + params)
  site_id       INTEGER NOT NULL REFERENCES site(id) ON DELETE CASCADE,
  method        TEXT    NOT NULL,
  payload       BLOB    NOT NULL,           -- gzip 压缩的 JSON
  bytes         INTEGER NOT NULL,
  expires_at    INTEGER NOT NULL,
  created_at    INTEGER NOT NULL
);
CREATE INDEX ix_site_cache_expiry ON site_cache(expires_at);
```

启动时与每小时清理过期项；总量超过上限（默认 200MB）时按 `created_at` LRU 淘汰。

### 3.11 `setting` — 应用设置 KV

```sql
CREATE TABLE setting (
  key           TEXT    PRIMARY KEY,
  value_json    TEXT    NOT NULL,
  updated_at    INTEGER NOT NULL
);
```

用 KV 而非宽表：设置项增删频繁，宽表每次都要迁移。类型安全靠 Dart 侧的 `SettingKey<T>` 常量表保证。

### 3.12 `search_history`

```sql
CREATE TABLE search_history (
  keyword       TEXT    PRIMARY KEY,
  hit_count     INTEGER NOT NULL DEFAULT 1,
  last_at       INTEGER NOT NULL
);
```

### 3.13 `app_event` — 结构化诊断日志

```sql
CREATE TABLE app_event (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  ts            INTEGER NOT NULL,
  level         TEXT    NOT NULL,           -- debug|info|warn|error
  scope         TEXT    NOT NULL,           -- spider|player|plugin|update|net
  site_id       INTEGER,
  code          TEXT,                       -- 错误码，见 08-RPC协议
  message       TEXT    NOT NULL,
  detail_json   TEXT
);
CREATE INDEX ix_app_event_ts ON app_event(ts DESC);
CREATE INDEX ix_app_event_scope ON app_event(scope, ts DESC);
```

保留最近 7 天或 50000 条（取先到者），启动时清理。源诊断面板直接查这张表。

## 4. 迁移策略

- drift 的 `MigrationStrategy`，`schemaVersion` 单调递增，**每次改表必须写迁移**，禁止靠 `deleteDb` 重建。
- 每个版本的 schema 快照存 `packages/storage/drift_schemas/`，CI 中用 drift 的迁移测试工具验证 **v(N-1) → v(N)** 与 **v1 → v(N)** 两条路径。
- 迁移前自动备份数据库到 `data/backup/mistream-v{old}-{ts}.db`，保留最近 3 份。
- 迁移失败 → 回滚到备份 + 弹窗告知 + 不进入主界面（宁可不启动，也不要带着半迁移的库跑）。
- **可重建数据**（`site_cache`、`app_event`、`site` 的运行时状态列）在迁移时允许直接清空，不必费力搬运。

## 5. 备份与导出

| 内容 | 是否进备份 |
| --- | --- |
| `favorite` / `history` / `setting` / `search_history` | ✅ |
| `config_source`（含 URL） | ✅（导出时可选择脱敏，去掉 URL 只留名称） |
| `plugin` 清单（id + version，不含二进制） | ✅ |
| `download` 任务与文件 | ❌（文件太大，只导出任务元数据） |
| `site_cache` / `app_event` | ❌ |

导出格式：单个 `.mistream-backup` 文件（实为 zip，内含 `manifest.json` + `data.json` + 可选加密）。导入时按表合并，冲突策略可选「保留本地 / 覆盖 / 保留较新」。

## 6. 加密

- 默认**不加密**——本地媒体客户端全库加密的性能与复杂度成本高于收益。
- 提供可选的「敏感字段加密」：`config_source.url`、`site.api`、`site.ext` 在用户开启后用主密码派生密钥（Argon2id）加密存储。
- 若后续需要全库加密，路径是 SQLCipher，但这会引入原生依赖与体积，**列为 v2.0 待评估项，不进 v1.0**。

## 7. 性能约束

| 操作 | 目标 |
| --- | --- |
| 冷启动读取设置 + 最近历史 | < 50ms |
| 历史列表分页（20 条） | < 10ms |
| 写播放进度 | < 5ms，且节流至 5s 一次 |
| 缓存查询 | < 5ms |

大列表一律分页查询 + `Stream` 增量渲染，禁止 `SELECT *` 全表加载到内存。
