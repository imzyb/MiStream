# 09 · UI 规范

## 1. 设计原则

1. **内容优先** — 封面与标题是主角，chrome 要退让。默认深色，因为这是一个长时间看视频的应用。
2. **桌面优先，不是移动端放大** — 鼠标悬停、右键菜单、键盘快捷键、多窗口、可调整的密度，都是一等公民。
3. **状态永远可见** — 加载中要说明在做什么（解析中/连接中/缓冲中），失败要说明为什么、能做什么。禁止无信息的转圈。
4. **不抢焦点** — 播放中不弹窗、不打断。通知走右下角轻提示。
5. **可降级不崩** — 主题包坏了、封面 404、源返回畸形数据，UI 都要有兜底渲染。

## 2. 设计令牌

主题系统的公共契约（插件通过 [06-插件系统](06-插件系统.md) §9 覆盖这些键）。

### 2.1 颜色

| 令牌 | 用途 | 深色默认 |
| --- | --- | --- |
| `color.primary` | 主色**填充**：按钮底色、选中态背景 | `#6B4EE6` |
| `color.onPrimary` | 主色填充上的文字 | `#FFFFFF` |
| `color.primaryText` | 主色**文字**：链接、强调文本、图标 | `#9B84FF` |
| `color.background` | 窗口底色 | `#0D0F14` |
| `color.surface` | 卡片、面板 | `#161A22` |
| `color.surfaceVariant` | 次级面板、输入框 | `#1E232D` |
| `color.onSurface` | 主文字 | `#E6E8EF` |
| `color.onSurfaceMuted` | 次要文字、说明 | `#98A0B3` |
| `color.outline` | 分隔线、边框 | `#2A303C` |
| `color.success` / `warning` / `error` | 状态色 | `#3DD68C` / `#FFB020` / `#FF5C5C` |
| `color.overlay` | 播放器控制栏遮罩 | `rgba(0,0,0,0.6)` |

**为什么主色拆成两个令牌**：单一中亮度主色无法同时满足「白字压在它上面」和「它压在深色背景上」两种用法的 AA 要求——前者要求它足够暗，后者要求它足够亮。强行用一个值，必然有一边不达标。因此 `color.primary` 取偏暗的填充色，`color.primaryText` 取偏亮的文字色，两者同色相。

参考对比度（`#0D0F14` 背景，按 WCAG 相对亮度公式）：

| 组合 | 比值 | 判定 |
| --- | --- | --- |
| `onPrimary` 白字 on `primary` | ≈ 5.4:1 | ✅ AA 正文 |
| `primary` on `background` | ≈ 3.5:1 | ✅ AA 大字/UI 组件（**不可用作正文**） |
| `primaryText` on `background` | ≈ 6.5:1 | ✅ AA 正文 |
| `onSurface` on `surface` | ≈ 11:1 | ✅ AAA |
| `onSurfaceMuted` on `surface` | ≈ 5.2:1 | ✅ AA 正文 |

上表数值为设计阶段的计算值。**令牌集必须附带自动化对比度测试**（`theme_engine` 的单测），对每一对前景/背景组合断言实际比值达标——包括内置主题与加载的主题包。数值以测试结果为准，不以本表为准。

浅色主题提供对应的一套，同样受该测试约束。对比度要求：正文 4.5:1，大字与 UI 组件 3:1。

### 2.2 尺度

| 令牌 | 值 |
| --- | --- |
| `spacing.unit` | 4（所有间距为其整数倍：4/8/12/16/24/32/48） |
| `radius.sm` / `md` / `lg` / `full` | 4 / 8 / 16 / 9999 |
| `elevation.card` / `dialog` / `overlay` | 1 / 8 / 16 |

### 2.3 字体

| 令牌 | 字号 / 字重 | 用途 |
| --- | --- | --- |
| `font.display` | 28 / 600 | 页面主标题 |
| `font.title` | 20 / 600 | 区块标题 |
| `font.subtitle` | 16 / 500 | 卡片标题 |
| `font.body` | 14 / 400 | 正文 |
| `font.caption` | 12 / 400 | 说明、角标 |

字体族：Windows 优先 `Microsoft YaHei UI` / `Segoe UI`，macOS `PingFang SC` / `SF Pro`，Linux `Noto Sans CJK`。允许主题覆盖，但必须校验字体存在，否则回退。

### 2.4 动效

| 场景 | 时长 / 曲线 |
| --- | --- |
| 悬停、点击反馈 | 120ms / `easeOut` |
| 页面切换 | 240ms / `easeInOutCubic` |
| 抽屉、弹窗 | 200ms / `easeOutCubic` |
| 播放器控制栏淡入淡出 | 180ms / `easeInOut` |

提供「减少动效」开关（也响应系统的无障碍设置），开启后全部降为 0ms。

## 3. 响应式断点

| 断点 | 宽度 | 导航形态 | 网格列数 |
| --- | --- | --- | --- |
| Compact | < 720 | 底部 NavigationBar | 3 |
| Medium | 720–1200 | 左侧 NavigationRail（图标） | 5 |
| Expanded | 1200–1600 | NavigationRail（图标+文字） | 6 |
| Large | > 1600 | 可展开侧边栏 | 7–8 |

窗口最小尺寸 800×600。网格用「最小卡片宽度 + 自适应列数」而非固定列数，避免断点处跳变。

## 4. 导航结构

```
┌─ 首页        推荐 + 按源浏览分类
├─ 搜索        聚合搜索
├─ 直播        频道列表 + 播放
├─ 媒体库      收藏 / 历史 / 下载
├─ 插件        已安装 / 市场
└─ 设置        通用 / 播放 / 源 / 网络 / 外观 / 高级 / 关于
```

播放器不在导航里——它是从任何位置进入的全屏/大窗口体验。

## 5. 页面规范

### 5.1 首次启动引导（Onboarding）

必须存在，因为**空壳交付**是产品的硬约束（[01-项目概述](01-项目概述.md) §6）。

```
1. 欢迎 + 一句话说明「MiStream 不含任何内容源」
2. 免责声明（用户对自己导入的内容负责），需勾选确认
3. 导入配置：粘贴 URL / 选择本地文件 / 暂时跳过
4. 解析结果预览：找到 N 个源、M 个直播分组、K 个解析器 → 确认导入
5. 完成
```

跳过后，首页显示明确的空态引导，而不是一片空白。

### 5.2 首页

- 顶部：源切换器（下拉，显示当前源与状态点）+ 全局搜索入口
- 中部：该源的分类横向标签（来自 `homeContent.classes`）
- 内容：`homeVideoContent` 推荐区 + 分类网格
- 筛选：源支持 `filterable` 时，标签下方显示筛选条（类型/地区/年份/排序）
- 无限滚动分页，滚动位置在页面切换后保留

### 5.3 搜索

- 输入框：历史建议、清空、回车触发
- **源选择器**：默认全选可搜索的源，可折叠为「已选 12/30 个源」
- 结果区：**流式渲染**，每个源的结果到达即插入，顶部进度条显示「已完成 8/30 个源」
- 每张结果卡片显示来源标识；同名作品的多源结果合并，展开后可选具体源
- 失败的源折叠在底部「3 个源未返回结果」，点开可看具体原因

搜索体验的核心是**永不阻塞**：慢源不影响快源的结果展示。

### 5.4 详情页

```
┌────────────┬──────────────────────────────────┐
│            │  标题                             │
│   封面      │  年份 · 地区 · 类型 · 更新状态      │
│            │  导演 / 主演                       │
│            │  [播放] [收藏] [下载] [切换源]      │
└────────────┴──────────────────────────────────┘
  简介（默认折叠 3 行）
  ── 播放线路 (flag) ────────────────
  [线路1] [线路2] [线路3]
  ── 剧集 ───────────────────────────
  [1][2][3][4]...   （已看的置灰，当前播放高亮，>50 集时分组）
```

- 「切换源」：同一作品在其它源的搜索结果，用于当前源失效时快速换源
- 剧集网格支持倒序、跳转到指定集

### 5.5 播放页

详见 [04-播放器设计](04-播放器设计.md) §10。UI 层要点：

- 三种形态：内嵌窗口 / 全屏 / 小窗（PiP）
- 控制栏 3 秒无操作自动隐藏；暂停时保持显示
- 右侧抽屉（剧集 / 线路 / 字幕音轨 / 设置）可开着继续播放，不遮挡画面主体（画面等比缩放而非被盖住）
- 加载态明确显示当前阶段与已耗时
- 错误卡片：错误码 + 人话说明 + 「换线路」「重试」「复制诊断信息」

### 5.6 直播

- 左：分组列表；中：频道列表（含台标、当前节目）；右：播放区
- 数字键直接输入频道号跳转
- `↑`/`↓` 上下换台，切换时保留上一路画面直到新流首帧到达（避免黑屏闪烁）
- 频道多地址时自动按顺序尝试，UI 显示「线路 2/4」

### 5.7 媒体库

三个 Tab：

- **收藏**：网格，支持自定义分组、拖拽排序、更新角标
- **历史**：列表，按日期分组，显示进度条与「继续观看第 N 集」
- **下载**：任务列表（进行中/已完成/失败），显示速度、剩余时间、暂停/继续/删除

### 5.8 插件中心

- **已安装**：卡片列表，显示类型徽章、版本、启用开关、更新提示
- **市场**：分类浏览 + 搜索，安装前弹出权限确认对话框（逐条列出权限与 reason）
- **插件详情**：说明、权限清单（可逐项撤销）、设置项、最近活动统计、卸载

### 5.9 设置

| 分组 | 内容 |
| --- | --- |
| 通用 | 语言、启动行为、窗口记忆、托盘 |
| 播放 | 默认清晰度、硬解方式、字幕样式、跳过片头片尾、连播、快捷键 |
| 源 | 配置管理（增删改、手动同步）、源列表与优先级、**源诊断面板** |
| 网络 | 代理、DoH、超时、并发上限、UA |
| 外观 | 主题、深浅色、字号缩放、卡片密度、减少动效 |
| 数据 | 缓存清理、备份导出/导入、数据目录位置 |
| 高级 | 日志级别、RPC 录制、运行时管理（安装 Python/JVM）、重置 |
| 关于 | 版本、更新检查、开源许可、免责声明 |

**源诊断面板**（[05-Spider引擎](05-Spider引擎.md) §5.4）是设置里最重要的页面，需要一个显眼入口，不能埋三层。

## 6. 通用组件

| 组件 | 要点 |
| --- | --- |
| `MediaCard` | 封面 16:9 或 2:3，懒加载 + 模糊占位 + 加载失败兜底图；角标（更新状态/来源）；悬停浮起 + 快捷操作 |
| `MediaGrid` | 自适应列数，滚动位置保持，分页加载哨兵 |
| `SourceChip` | 源标识 + 状态点（绿=就绪 黄=慢 红=熔断 灰=不支持） |
| `AsyncBuilder` | 统一封装 loading / empty / error 三态，禁止各页面各写一套 |
| `EmptyState` | 图标 + 一句说明 + 一个主行动按钮，绝不只显示"暂无数据" |
| `ErrorCard` | 错误码 + 人话 + 重试/诊断动作 |
| `ContextMenu` | 桌面右键菜单，卡片、列表项均支持 |

## 7. 状态设计规范

**每个异步区域必须定义四态**，缺一不可：

| 态 | 规范 |
| --- | --- |
| Loading | 骨架屏（不是转圈）；超过 3s 追加当前阶段文字说明 |
| Empty | 图标 + 原因 + 行动。区分「没有数据」和「没有源」两种空 |
| Error | 可读原因 + 错误码 + 重试按钮；不显示原始异常堆栈（收进「复制诊断信息」） |
| Success | 内容 |

评审规则：任何新页面 PR，如果四态没写全，不予合并。

## 8. 键盘与无障碍

- 全局：`Ctrl+F` 搜索、`Ctrl+,` 设置、`F11` 全屏、`Esc` 返回/退出全屏、`Ctrl+W` 关闭窗口
- Tab 焦点顺序符合视觉顺序，焦点环清晰可见（不得为了美观移除）
- 所有可交互元素有语义标签（`Semantics`），支持屏幕阅读器
- 支持系统字号缩放（0.8×–1.5×）
- 颜色不作为唯一信息载体（状态点同时带形状或文字）
- 遥控器/手柄的方向键焦点导航：v2.0 的 TV 模式再做，但焦点系统从一开始就按「键盘可完全操作」设计

## 9. 主题系统

- 内置：深色（默认）、浅色、跟随系统、OLED 纯黑
- 主题包：JSON 令牌覆盖（见 [06-插件系统](06-插件系统.md) §9）
- 切换即时生效，无需重启
- **健壮性**：未知令牌忽略、缺失令牌取默认、非法值回退并在日志中告警。主题永远不能导致白屏或不可读的对比度——加载后自动做一次对比度检查，不达标则回退到内置主题并提示。

## 10. 文案规范

- 中文为主语，术语统一：「源」不叫「站点/接口」，「线路」不叫「flag/播放源」，「解析器」不叫「jx/解析接口」
- 错误文案三段式：**发生了什么 + 可能原因 + 你能做什么**
  - ✅「无法获取播放地址：该源返回了空结果。可以尝试切换其它线路，或在源诊断中查看详情。」
  - ❌「playerContent failed: null」
- 按钮用动词（「导入配置」而非「配置」）
- 不用感叹号，不用「哦」「呢」等语气词
