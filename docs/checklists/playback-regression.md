# 播放回归检查清单

每次 release 前手工执行。自动化测试能覆盖编排逻辑，但**画面对不对、音画同不同步、字幕好不好看，只能靠眼睛**。

样本文件放在 `tools/media-samples/`（不进仓库，从内部存储获取，清单见 `tools/media-samples/README.md`）。

记录格式：`✅通过 / ⚠️降级但可用 / ❌失败`，失败项必须有 issue 编号。
